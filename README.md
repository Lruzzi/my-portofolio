# Ghulam Izzul Fuad - Software Developer Portfolio

A modern, responsive, and mobile-first portfolio website designed with a sleek, dark aesthetic. This project showcases my professional background, technical skills, and work experience.

## ✨ Features
- **Mobile-First Design**: Optimized for all screen sizes, from mobile phones to high-resolution desktops.
- **Modern UI/UX**: Includes glassmorphism effects, radial gradients, and smooth animations.
- **Sticky Navigation**: A glass-effect header that stays at the top, plus an off-canvas mobile sidebar.
- **Experience Timeline**: A clean layout of professional history extracted from LinkedIn.
- **Interactive Contact Form**: A styled contact section with focus-glow effects.
- **Smooth Scrolling**: Enhanced navigation experience using smooth scroll behavior.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, and Media Queries.
- **JavaScript**: Logic for sidebar toggling and interactive elements.
- **Font Awesome**: High-quality vector icons for social media and navigation.

## 🚀 Getting Started
1. Clone or download the repository.
2. Open `portofolio.html` in any modern web browser.

## 📂 Project Structure
- `portofolio.html`: The main entry point and structure of the site.
- `style.css`: The complete styling system, including responsive breakpoints.
- `images/`: Directory containing personal profile pictures and assets.
